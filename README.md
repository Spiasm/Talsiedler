# Talsiedler

Ein Aufbauspiel für Android-Tablets im Stil der alten Siedler-Klassiker – mit eigener Grafik, eigenem Namen.

**Download:** [Talsiedler.apk](https://github.com/Spiasm/Talsiedler/releases/latest/download/Talsiedler.apk)

## Stufe 1 (aktueller Stand)
- Zufällige Karte mit Wiesen, Wäldern, Bergen, Seen und Steinen
- Hauptquartier mit Lager, Siedlern und Soldaten
- Fahnen und Wege, auf jedem Wegstück ein Träger, Waren werden von Fahne zu Fahne gereicht
- Baustellen mit Bauarbeiter, Material wird angeliefert
- Holzfäller, Förster, Steinbruch, Sägewerk
- Wachstube und Wachturm vergrößern das Land
- Tipps für den Einstieg, automatisches Speichern

## Geplant
